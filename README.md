# Тіл Mix

Веб-тренажёр казахского, английского и турецкого для студентов. В коротких историях ученик выбирает реплику, получает пояснение и открывает одну из концовок.

- 51 история уровней A1–A2 и 204 концовки: 27 казахских, 12 английских и 12 турецких уроков. В новых курсах есть кафе, знакомство, покупки, дорога, автобус, встречи, гостиница, поезд, ресторан, учёба, работа и выходные.
- Язык выбирается в шапке и сохраняется в браузере. Меню «Занятия» объединяет разделы. Маршрут, каталог, словарь, повторение, тесты и помощник используют выбранный курс. XP, серия и недельная цель общие; уроки и результаты глав хранятся раздельно. Ссылки `?lang=en` / `?lang=tr` открывают курс, `?lesson=tr-hotel` — конкретный урок.
- Словарь с поиском по реплике и русскому переводу, избранным и фильтром по уроку. Из концовки можно открыть словарь истории и пройти тест по её фразам.
- [ИИ-помощник](https://ameke111.github.io/til-mix/#assistant) принимает вопросы по-русски и по-казахски, подбирает переводы, пояснения и уроки. Его можно открыть из навигации или внутри истории для разбора текущей реплики.
- Семнадцать глав маршрута: девять в казахском курсе, по четыре в английском и турецком. Семь уровней и девять достижений. За новую концовку начисляются 10 XP, за открытие всех концовок урока даётся ещё 15 XP.
- У каждой главы своя проверка из пяти вопросов по её диалогам. Результаты 2/5, 4/5 и 5/5 открывают звёзды. Каждая звезда один раз приносит 5 XP, лучший результат хранится в профиле.
- Тренажёр из 90 реплик охватывает все уроки: 42 на казахском и по 24 на английском и турецком. Собирай ответ из слов или печатай его; для казахского и турецкого есть кнопки специальных букв. Первый верный ответ без подсказок и ошибок даёт 3 XP за сборку и 5 XP за письменный перевод. Фразы с ошибками или открытым ответом добавляются в карточки.
- Аудирование с 15 записями. В каждом раунде пять фраз, есть выбор уровня, повтор и замедление, расшифровка и ссылка на диалог. За первый верный ответ на запись даётся 2 XP. [Источник озвучки](audio/README.md)
- Произношение с 15 образцами. Браузер записывает голос по нажатию, позволяет сравнить запись с образцом и даёт подсказки по громкости и темпу. Проверка слов показывает распознанный текст и совпадения. Запись хранится в памяти открытой страницы.
- Недельная цель на маршруте, очередь карточек и календарь занятий за 28 дней с различением шести видов практики.
- Три задания дня: пройди выбранный диалог, набери 3 из 5 в тесте и повтори три разные фразы. Каждое даёт 5 XP один раз в день, все вместе приносят ещё 15 XP. В профиле видны серия и цель недели.
- Карточки с интервалами 1, 3, 7, 14 и 30 дней. Реплики и ошибки из теста добавляются в очередь. Можно также выбрать фразы вручную.
- Тренировка из пяти вопросов в двух направлениях перевода с выбором темы.
- «Работа над ошибками» собирает фразы из теста, аудирования и мастерской. В тренировке до пяти фраз, исправленные ответы убираются из очереди.
- Гостевой профиль, настраиваемая цель, экспорт и объединение копий прогресса.
- Прямые ссылки на уроки и форма обратной связи. Гость скачивает заметку, а аккаунт сохраняет обращения на сервере.
- В серверной версии есть регистрация, вход, выход, личные настройки, удаление аккаунта и сохранение прогресса с проверкой версии записи.
- Записи аудирования входят в сборку. Для озвучки остальных фраз используется системный голос `kk-KZ` через Web Speech API, если устройство его предоставляет.
- Интерфейс, графика на CSS, анимации с поддержкой `prefers-reduced-motion`.

## Запуск

Нужен Node.js 24 или новее.

```sh
npm ci
npm run lint
npm test
npm run build
npm start
```

Открой [http://127.0.0.1:4173](http://127.0.0.1:4173) и нажми «Войти», чтобы создать аккаунт. Сервер пишет базу в `.til-data/til-mix.sqlite`. Для другого файла задай переменную `TIL_DB`. Пароль хранится как хеш с уникальной солью, токен сессии выдаётся в HttpOnly-cookie. Прогресс гостя можно добавить к аккаунту из профиля.

[GitHub Pages](https://ameke111.github.io/til-mix/) и `npm run dev` запускают гостевой вариант. Публичная серверная площадка потребует выбранного хостинга, HTTPS с точным `TIL_ORIGIN`, настройки оператора данных и плана резервных копий. Локальный запуск рассчитан на loopback. [Решение по аккаунтам](course/adr-002.md)

esbuild собирает приложение в `dist/`. `npm run preview` открывает гостевую сборку на порту 4174. Сценарии находятся в `stories.js` и `extra-stories.js`, повторы — в `learning.js`, XP и задания дня — в `game.js`, тренажёр фраз — в `studio.js` и `studio-ui.js`, SQLite и API — в `server.js`.

### ИИ-помощник

Справочник подбирает материалы выбранного курса. Нейросеть получает его язык и контекст урока. Локальная Qolda рассчитана прежде всего на казахский: качество английских и особенно турецких объяснений нужно проверять. Записанное аудирование и проверка произношения пока доступны только в казахском курсе; озвучка английских и турецких фраз использует голоса устройства при их наличии.

Режим «Нейросеть» обращается к языковой модели через Node.js. Модель получает последние сообщения и контекст открытого урока, поддерживает свободный диалог и объяснения ошибок. Ответ выводится как текст, переписка хранится в памяти вкладки. Есть остановка, повтор при сбое и очистка истории. Ответы модели требуют проверки, особенно объяснения грамматики.

На подготовленном компьютере запуск локальной модели и сайта выполняется одной командой после сборки.

```sh
npm run build
npm run ai
```

Открой [Тіл Mix с нейросетью](http://127.0.0.1:4176/#assistant). Скрипт запускает отдельный процесс модели с временным ключом и завершает его при Ctrl+C. Используется текстовая часть Qolda от ISSAI, квантование Q4_K_M, контекст 8192 токена и перенос слоёв на GPU. Для другого компьютера нужны [llama.cpp для Windows CUDA 12.4, выпуск b12521](https://github.com/ggml-org/llama.cpp/releases/tag/b12521), его CUDA runtime и [Qolda GGUF от ISSAI](https://huggingface.co/issai/Qolda_GGUF/tree/main/Q4_K_M). Распакуй оба ZIP в `.til-data/llama-cuda/`, помести модель в `.til-data/Qolda-Q4_K_M.gguf`. SHA-256 модели `670a2c7a8b09bdf70c35b2b4d26a0c3bab182b78164a18266161c3cdb7b1c74d`. Переменные `TIL_LLAMA_EXE`, `TIL_GGUF`, `TIL_GPU_LAYERS`, `TIL_MODEL_PORT` и `PORT` позволяют изменить пути и параметры. Для CPU задай `TIL_GPU_LAYERS=0`.

Для другого сервиса с совместимым Chat Completions API задай на сервере `TIL_AI_URL` с полным адресом endpoint, `TIL_AI_MODEL` и при необходимости `TIL_AI_KEY`, затем запусти `npm start`. Ключ остаётся на сервере. История и вопросы передаются выбранному поставщику. На публичном сервере запросы требуют входа в аккаунт. Действуют ограничение частоты, один одновременно выполняемый запрос и тайм-аут 120 секунд.

GitHub Pages обслуживает статические файлы. Режим нейросети работает на Node.js-сервере. Для публичного запуска нужен хостинг этого сервера с HTTPS и доступ к модели.

У каждой найденной реплики есть разбор, добавление в карточки и практика письменного перевода. В практике доступны казахская клавиатура, подсказка и сравнение порядка слов. После ответа можно спросить «Объясни проще» или «А какой урок?». Переписка помнит последнюю выбранную фразу в текущем сеансе. Проверка практики сравнивает ответ с репликой урока с учётом казахских букв, игнорируя регистр и пунктуацию.

В режиме «Фразы из уроков» модуль `assistant.js` подбирает тип вопроса методом ближайших размеченных примеров с весами для слов и символьных триграмм. Для ответа он ищет реплики в сценариях или пояснения в `assistant-data.js`. Покрытие этого режима ограничено материалами сайта, вопросы обрабатываются в браузере без сети. Функция работает отдельно от эксперимента по автоматической классификации ошибок в [ЛЗ 12](course/lab-12.md).

### Распознавание речи

Для проверки слов в локальной сборке перед `npm run build` один раз выполни `python prepare-speech.py` с Python 3.11 или новее. Скрипт проверяет контрольную сумму официального архива и готовит около 60 МБ данных, которые сборка копирует в `dist/assets/`. На GitHub Pages этот шаг выполняется автоматически. Браузер загружает модель при нажатии «Проверить слова». Запись, громкость и прослушивание доступны также локально до подготовки модели. Микрофону нужен HTTPS или loopback.

Распознавание выполняется на устройстве с [казахской моделью Vosk](https://github.com/alphacep/vosk-space/blob/master/models.md#kazakh) и [Vosk Browser](https://github.com/ccoreilly/vosk-browser). В календарь попадает отметка о занятии. Аудио и распознанный текст остаются в текущем сеансе браузера. Для отдельных звуков и акцента сверяйся с образцом на слух. ## Панель владельца

Для демонстрации выполни `npm run demo`, открой [демо Тіл Mix](http://127.0.0.1:4180/) и нажми «Открыть демо-админку». В очереди будут готовые учебные обращения. Демо запускается с отдельной базой в памяти и восстанавливает начальные данные при перезапуске.

В серверной версии открой сайт и создай отдельный аккаунт владельца. В терминале из папки проекта выполни `npm run admin -- grant <логин>`. Затем обнови страницу. В профиле появится «Панель владельца» с количеством аккаунтов, очередью обращений и фильтром закрытых. Статус обращения доступен ученику в его личной истории.

Для отзыва доступа выполни `npm run admin -- revoke <логин>`. Команда меняет роль только у существующего локального аккаунта и использует ту же базу, что сервер. Если сервер запущен с `TIL_DB`, укажи тот же путь в терминале. Обращения хранятся до 90 дней.
