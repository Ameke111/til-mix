# Тіл Mix

Веб-тренажёр разговорного казахского для студентов. В коротких историях ученик выбирает реплику, получает пояснение и открывает одну из концовок.

- Шесть историй уровней A1–A2 и 24 концовки.
- Словарь из фраз историй с поиском на казахском и русском и избранным.
- Маршрут из трёх этапов, XP, серия дней, недельная цель и ежедневный вызов.
- Карточки с интервалами 1, 3, 7, 14 и 30 дней. Реплики и ошибки из теста добавляются в очередь. Можно также выбрать фразы вручную.
- Тренировка из пяти вопросов в двух направлениях перевода с выбором темы.
- Сохранение в localStorage. Озвучка использует системный голос `kk-KZ` через Web Speech API, если устройство его предоставляет.
- Интерфейс, графика на CSS, анимации с поддержкой `prefers-reduced-motion`.

## Запуск

Нужен Node.js 22.12+ или 24 LTS.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Vite собирает приложение в `dist/` с относительными путями, пригодными для размещения в подпапке GitHub Pages. Страницы сайта работают без регистрации и серверной базы. Сценарии находятся в `stories.js`, интерфейс и прогресс — в `app.js`, правила календаря, повторения и сборки теста — в `learning.js`.
