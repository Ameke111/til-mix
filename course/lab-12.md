# ЛЗ 12. План ИИ-подсказки, evals, стоимость и риски

**Тіл Mix, неделя 12 · 23–29 ноября 2026.** Эксперимент проведён досрочно 18 ноября. Решение — оставить подсказку экспериментом, дальнейший выпуск зависит от результатов проверки качества.

## 1. Карточка функции

После неверного письменного ответа ученик может попросить подсказку. Классификатор распознаёт, что полезнее проверить, буквы, форму глагола или порядок слов. Код продукта по метке выбирал бы короткую подсказку из текстов, предварительно вычитанных преподавателем. При нехватке контекста предлагается повторить упражнение или посмотреть исходную реплику. Баллы и принятие ответа определяются существующей проверкой.

| Что измеряем | Как проверяем | Порог для следующего этапа |
|---|---|---|
| Правильный ответ со второй попытки | Доля успешных следующих попыток после ошибки, пары сопоставимых заданий с подсказкой и с текущей обратной связью | Не менее +8 процентных пунктов в пилоте. Нужна отдельная запись фактической выборки |
| Качество метки | Macro-F1 по четырём классам и recall класса `unclear` | Macro-F1 ≥ 0,85 и минимум +0,05 к правилам. Recall `unclear` ≥ 0,875 |
| Границы и отказ | В случае неоднозначности или команды, вложенной в ответ, просим уточнение | Ноль невалидных меток и ноль выполненных вложенных команд в регрессионном наборе |
| Скорость и бюджет | p95 ответа и расходы на 30 000 запросов в месяц | p95 ≤ 800 мс, до 2 USD за инференс при принятых допущениях |

## 2. Эксперимент

В [эталонном наборе](lab-12-eval.tsv) 32 синтетических сообщения, по восемь на каждый класс. Метки подготовлены заранее. Есть русский, казахский, смешанные формулировки и одна вложенная команда в строке 32. В класс `unclear` входят также технические обращения и случаи без исходного ответа. Размер подходит для упражнения с evals. Перед пилотом нужна новая выборка, вычитка носителем и отдельный набор сложных примеров.

[Скрипт](lab-12-eval.py) сравнивает два способа на одних входах. Первый ищет признаки регулярными выражениями, иначе возвращает `unclear`. Второй даёт запрос локальной Qwen2.5-0.5B-Instruct Q4_K_M и принимает только одну из четырёх меток. Для копии стенда использовались CPU, четыре потока, llama.cpp b12521, температура 0, seed 42, до 12 токенов ответа. Один запрос прогрева исключён. [Карточка модели и веса](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/tree/9217f5d) · [Релиз llama.cpp](https://github.com/ggml-org/llama.cpp/releases/tag/b12521)

| Способ | Верных из 32 | Macro-F1 | Recall `unclear` |
|---|---:|---:|---:|
| Правила | 22 · 68,75% | 0,7015 | 8/8 |
| Qwen локально | 11 · 34,38% | 0,2249 | 0/8 |

У модели все ответы были синтаксически допустимыми, но восемь ошибок с буквами и восемь неясных запросов получили метку `verb` или `order`. Из глагольных ответов верны 7/8, из порядка слов — 4/8. Строка 32 с вложенной командой получила навязанную метку `order`. Локальная задержка p95 составила 432 мс. Токенизатор модели насчитал в среднем 134,75 входного и 2 выходных токена. [Полные ответы, токены и задержки](lab-12-results.json)

Для воспроизведения скачать `qwen2.5-0.5b-instruct-q4_k_m.gguf` из указанного снимка, сверить SHA-256 `74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db`. Запустить сервер на loopback, затем скрипт из корня проекта.

```powershell
llama-server.exe -m qwen2.5-0.5b-instruct-q4_k_m.gguf --host 127.0.0.1 --port 8012 -t 4 -c 1024 --alias qwen2.5-0.5b-instruct-q4_k_m
python course/lab-12-eval.py
```

## 3. Смета на месяц

Допущение для пилота — 3 000 запросов. Сценарий ×10 — 30 000. Всегда включённая аренда — 720 часов по наблюдаемой цене 0,27 USD/час для RTX 4090 на Vast.ai. Цена динамическая, дата среза 18 ноября 2026. Сравнение API берёт короткий запрос без кэша по стандартному тарифу GPT-6 Luna, 0,10 USD за миллион входных и 0,50 USD за миллион выходных токенов. Стоимость запроса с измеренными Qwen токенами как приближением — `(134,75 × 0,10 + 2 × 0,50) / 1 000 000 = 0,000014475 USD`. Перед покупкой нужны пробный счёт поставщика и проверка фактических токенов. [Тариф GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) · [Тариф аренды GPU](https://vast.ai/article/how-much-does-it-cost-to-rent-a-gpu-in-the-cloud-live-pricing-guide)

| Сценарий | API, USD/мес | Один постоянно включённый GPU, USD/мес |
|---|---:|---:|
| 3 000 запросов | 0,0434 | 194,40 |
| 30 000 запросов | 0,4343 | 194,40 |
| Чувствительность, 30 000 запросов по 300 входных и 40 выходных токенов | 1,50 | 194,40 |

Паритет прямых затрат по первому профилю — **13,43 млн запросов в месяц** (194,40 / 0,000014475). Это около 5,18 запроса/с в среднем. GPU-ёмкость, эксплуатация, сеть, налоги, возможное ожидание и проверка преподавателем вынесены из расчёта. GPU должен отдельно подтвердить нужную пропускную способность. API-вариант здесь оценён по цене, сравнение качества проводилось на локальной модели. Эксперимент на имеющемся CPU не потребовал платных запросов или аренды.

## 4. Риски и решение

| Риск | Мера и ответственный |
|---|---|
| Неверная подсказка закрепляет ошибку | Студент передаёт текст шаблона на проверку преподавателю. Отказ от автоматической публикации свободного текста |
| Подмена инструкций фразой ученика | Только перечислимые метки, ответ строго валидируется, непонятное уходит на уточнение. Регрессия по строке 32 обязательна |
| Ответ содержит имя, контакты или лишний контекст | Для экспериментального прогона только синтетические примеры. Перед внешним API отдельное решение по данным. Исключить профиль, историю и идентификаторы из payload |
| Неожиданные расходы и задержки | Лимит на длину, бюджет, тайм-аут, локальный статический fallback. Замер качества и затрат на стенде |
| Ученик принимает результат за проверку преподавателем | При допуске помечать «ИИ-подсказка» и пояснять, что она помогает выбрать следующий шаг. При жалобе доступна проверка человеком |
