# ADR 003. Границы эксперимента с ИИ-подсказкой

**Принято 18.11.2026.** Ученик должен получать полезное направление для второй попытки. Баллы и принятие ответа остаются за кодом тренажёра. Преподаватель отвечает за проверку педагогических формулировок.

**Решение.** Оставить детерминированный сценарий сайта, включая работу над ошибками и карточки. Код локального eval хранится в материалах курса. Модель и вызов внешнего сервиса в пользовательскую сборку не входят.

**Основание.** Локальный эксперимент дал 11/32 против 22/32 у правил. Модель не распознала ни одного `unclear` и приняла вложенную команду за метку. Стоимость API сама по себе этих результатов не исправляет. [Эксперимент и расчёт](lab-12.md)

**Когда пересмотреть.** Нужны независимая разметка новых русских и казахских примеров, достижение порогов ЛЗ 12, проверенные преподавателем шаблоны, ограниченный сбор данных и измерение улучшения второй попытки. Если пилот состоится, функционал включается флагом и отключается при сбоях качества, задержки или бюджета.
