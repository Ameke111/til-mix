## Проект Тіл Mix · осень 2026

- Спланировал курс разработки на 15 недель, подготовил устав, модель бюджета, дорожную карту, бэклог и оценку сроков с Monte Carlo.
- Разработал веб-тренажёр казахского на JavaScript и Node.js с SQLite, ветвящимися уроками и обновляемым учебным прогрессом. Срез защиты включает 21 урок, 84 концовки и 30 упражнений.
- Подготовил CI в GitHub Actions, провёл внутренний прогон девяти приёмочных сценариев и оформил разбор остановки выпуска с планом корректирующих действий.
- Собрал дашборд поставки и ранжировал десять инициатив по WSJF. Сравнил простые правила и локальную модель на 32 примерах и зафиксировал решение по выпуску.

**Навыки.** Декомпозиция работ, приоритизация, критерии приёмки, RAID, WSJF, метрики потока и DORA. GitHub Projects, GitHub Actions, Node.js, SQLite, Python, Jupyter.
